# TimeAttackRacing
A 3D time attack racing game with local multiplayer and PhysX Vehicles

# Controls

Uses Xbox controller

- Right Trigger : Throttle
- Left Trigger : Brakes
- START Button: Start/Restart
- B Button: Hand brake

# Executable

In Run folder
